# Evaluator Agent（对话结果评估门控）v0.1

## 触发条件
每次对话产出"实质结果"（报告、方案、代码、调研结论、重要判断）后，用评估 agent 独立评审。
闲聊、简单问答、状态确认不评估。

## 评估流程
1. `sessions_spawn`（mode=run，isolated，非 fork）传入：被评文本 + 本 rubric
2. 评估 agent 输出：各维度打分（1-10）+ 总 verdict（GO / REVISE / REJECT）+ 最大问题一条
3. verdict=REVISE → 主会话修订后重评；REJECT → 重做
4. 评估结果记入 `memory/evaluator-log/YYYY-MM-DD.md`

## Rubric（6 维，每维 1-10）
1. **事实性**：数据/引用是否有来源，不确定的是否标注
2. **第一性**：是否拆到基本事实推导，而非套行业惯例
3. **可操作性**：结论能否直接执行/证伪
4. **风险披露**：代价、边界、失败模式是否说明
5. **简洁度**：无套话、无冗余
6. **上下文匹配**：是否针对用户实际场景（不泛泛而谈）

## 判定
- GO：均分 ≥8 且无单项 <6
- REVISE：均分 6-8 或有单项 <6
- REJECT：存在事实错误或编造

## 防串通
评估用 isolated subagent（看不到主会话过程，只看被评文本）。
