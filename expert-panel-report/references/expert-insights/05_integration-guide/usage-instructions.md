# Rick Rule & Money of Mine 参考库 — 使用说明

## 快速开始

### 报告写作时的调用顺序
1. **确定报告主题** → 选择对应商品的 `02_core-content/*-insights.json`
2. **选择分析框架** → `04_analysis-frameworks/macro-analysis-structure.json`
3. **选用权威表达** → `03_expression-templates/authority-expressions.json`
4. **引用风险表达** → `03_expression-templates/risk-assessment-phrases.json`
5. **撰写结论** → `03_expression-templates/conclusion-templates.json`
6. **引用专家观点** → `01_rick-rule/key-insights.json`

## 各文件用途速查

| 文件 | 用途 | 优先级 |
|------|------|--------|
| `01_rick-rule/key-insights.json` | Rick Rule真实引用，用于报告权威背书 | 最高 |
| `01_rick-rule/investment-philosophy.json` | 投资哲学框架，用于分析逻辑构建 | 高 |
| `02_core-content/*-insights.json` | 各商品专家观点，按主题引用 | 高 |
| `03_expression-templates/authority-expressions.json` | 权威开场表达模板 | 中 |
| `03_expression-templates/risk-assessment-phrases.json` | 风险表达模板 | 中 |
| `03_expression-templates/conclusion-templates.json` | 结论表达模板 | 中 |
| `03_expression-templates/sector-vocabulary.json` | 各商品专业词汇 | 参考 |
| `04_analysis-frameworks/macro-analysis-structure.json` | 完整报告结构框架 | 高 |
| `05_integration-guide/integration-examples.json` | 使用前后对比示例 | 参考 |

## 质量原则

- **禁止臆造**：所有引用必须来自真实采访或真实数据
- **语境完整**：引用时保留足够上下文，避免断章取义  
- **周期意识**：所有分析嵌入周期框架（Rick Rule核心方法论）
- **风险平衡**：看涨论点必须配套风险提示
