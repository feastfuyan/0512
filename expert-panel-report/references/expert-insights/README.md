# Expert Insights References - 专家洞察参考库

## 📋 概述

本目录包含来自顶级投资专家的核心洞察和专业表达模式，专门用于提升宏观经济报告的质量和权威性。

## 📚 内容类型

### 1. 专家访谈精华 (`01_rick-rule/`)
- **内容**: 清理和结构化的专家核心观点
- **用途**: 作为高质量参考内容的来源
- **特点**: 去除噪音，保留精华，按主题组织

### 2. 权威表达模板 (`03_expression-templates/`)
- **内容**: 35个分类的权威表达模板
- **类型**: 开头权威、确定性判断、经验智慧、风险评估等
- **用途**: 直接应用于报告写作，提升表达的专业性

### 3. 分析框架 (`04_analysis-frameworks/`)
- **内容**: 完整的6步宏观分析结构
- **覆盖**: 从执行摘要到结论展望的完整框架
- **特点**: 体现Rick Rule的分析方法论和思维模式

### 4. 专业术语库 (`05_professional-vocabulary/`)
- **内容**: 60个核心投资术语及其专业定义
- **分类**: 投资概念、风险管理、市场分析、投资策略等
- **特点**: 包含Rick Rule的使用语境和实际示例

## 🎯 使用方法

### 报告生成时的调用顺序
1. **确定报告主题和目标**
2. **选择适当的分析框架**（从 `04_analysis-frameworks/`）
3. **选用相关的权威表达**（从 `03_expression-templates/`）
4. **引用专业术语**（从 `05_professional-vocabulary/`）
5. **参考专家原始洞察**（从 `01_rick-rule/`）

### 质量提升策略
- **开头建立权威**: 使用权威表达模板
- **分析体现专业**: 采用标准分析框架
- **表达精准专业**: 运用准确的专业术语
- **结论权威可信**: 体现专家级判断力
