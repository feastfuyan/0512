# 体型与版型

> 穿搭的第一原则：**扬长避短**。先看优点（腰/腿/肩/颈），把视觉焦点引到优点上。
> 版型建议是通用规律；用户有明确偏好（如"我就喜欢 oversize"）时尊重用户。

## 一、男士体型

| 体型 | 特征 | 版型策略 |
|------|------|---------|
| 倒三角 | 肩宽胸厚腰窄 | 上装合身即可，下装选直筒；避免过紧上衣 |
| 矩形/瘦高 | 肩腰臀接近 | 增加上身体量（叠穿/肩部细节）；避免太宽松 |
| 梨形（下身胖） | 臀腿偏大 | 深色直筒/锥形裤 + 上装亮点；避免紧身浅色裤 |
| 苹果形（肚腩） | 腰腹偏大 | 上装略宽松盖腰，裤装合身；避免紧身T恤 + 低腰 |

## 二、女士体型

| 体型 | 特征 | 版型策略 |
|------|------|---------|
| X型/沙漏 | 肩胯等宽腰细 | 收腰设计、腰带、高腰裤（发挥腰线） |
| H型/直筒 | 三围接近 | 制造腰线（腰带/塞衣角/叠穿）；避免直筒到底 |
| A型/梨形 | 胯臀偏大 | 上宽下窄：上装亮点 + 深色直筒/阔腿裤；避免紧身包臀 |
| O型/苹果 | 腰腹偏大 | V领拉长颈线 + 上装略宽松 + 垂坠感下装 |
| I型/细长 | 骨架细 | 叠穿/层褶/泡泡袖增加体量；避免全身紧身 |

## 三、版型选择速查

- 肩窄 → 选肩部有结构的（垫肩、正肩线）
- 肩宽 → 避开夸张垫肩/泡泡袖，选落肩或 V 领
- 腰粗 → 避开紧身 + 死板塞衣角，选垂坠面料/高腰 A 字
- 腿粗 → 直筒/阔腿/锥形裤，避开紧身浅色
- 腿短 → 高腰裤/裙 + 上短下长 + 鞋裤同色
- 个子矮 → 同色系延伸、腰线上移、裤长露脚踝
- 个子高 → 长款单品（长大衣/长裙）撑得起，避免全身堆积

## 四、显高显瘦通用法则

1. 腰线即生命线：能显高 5cm（高腰下装、塞衣角、腰带）
2. 上短下长：视觉重心上移
3. 鞋裤同色：腿部视觉延伸
4. 同色系延伸：全身同色系显高显瘦
5. 露肤留白：露脚踝/手腕/锁骨，显轻盈
6. 深色收缩：想显瘦的部位用深色
7. 竖线条优先：竖条纹/长拉链/直筒 > 横条纹/宽格纹
8. 配饰上移：焦点放上半身（领口/耳饰/项链）

## 五、注意

- 体型建议作为"加分项"简短说明即可，不要长篇大论，避免冒犯
- 女性用户避免直接说"胖/瘦"，用"腰线""比例"等中性表述
