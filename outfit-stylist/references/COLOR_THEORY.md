# 色彩搭配体系

## 一、色彩三要素

- 色相（Hue）：颜色的类别，红橙黄绿蓝紫…
- 明度（Value）：颜色的明暗，加白变浅、加黑变深
- 纯度（Saturation）：颜色的鲜艳度，纯色 → 灰浊色

判断一件衣服颜色：先定色相 → 再看明度（深/浅）→ 再看纯度（鲜艳/灰浊）。
例："藏青" = 蓝色相 + 低明度；"雾霾蓝" = 蓝色相 + 高明度 + 低纯度。

## 二、和谐配色六法（核心方法论）

1. **同色系**：同一色相不同明度/纯度（深蓝 + 浅蓝）。最稳妥、最显高级
2. **邻近色**：色轮上相邻 30-60°（蓝 + 蓝绿 + 绿）。自然和谐
3. **互补色**：色轮对侧 180°（红+绿、蓝+橙、黄+紫）。大胆醒目，需用明度/纯度调和（如酒红+墨绿）
4. **三角色**：色轮等距三分（红黄蓝）。鲜艳个性，日常使用要降纯
5. **无彩色 + 跳色**：黑白灰打底 + 一个亮色点缀。最不容易出错，适合所有风格
6. **单色层次**：全身同一色系（不同明度），靠材质与层次区分。高级感公式

## 三、中性色体系（打底万能）

- 深色系：黑、藏青、炭灰、深棕、酒红
- 浅色系：白、米白、燕麦、浅灰、卡其、奶油
- 中性色的作用：70% 基础 + 25% 过渡 + 5% 跳色
- 全身不超过 2 个有彩色（图案色算作有彩色）

## 四、肤色适配

- 判断方法：手腕血管偏蓝紫 = 冷皮；偏绿 = 暖皮；难判断 = 中性皮
- **冷皮**（偏白/粉调）：适合 蓝、紫、玫红、正红、纯白、灰。避开：荧光黄、土黄、卡其（显黄气）
- **暖皮**（偏黄/小麦）：适合 米色、驼色、砖红、橄榄绿、藏青、奶白。避开：荧光粉、冷紫、宝蓝
- **中性皮**：全色系基本可穿，用风格定
- 通用安全色：藏青、米白、燕麦、灰（任何肤色）

## 五、色彩心理速查

- 黑：权威、正式、显瘦
- 白：清爽、干净、显年轻
- 藏青：专业、稳重（通勤首选）
- 灰：中性、高级、百搭
- 卡其/驼色：温暖、知性（秋冬主力）
- 红：气场、吸睛（点缀色之王）
- 蓝：冷静、信赖（牛仔色天然百搭）
- 绿：活力、自然（橄榄绿更高级）
- 黄：醒目、活泼（明度降低才日常）
- 粉：柔和、甜美（灰粉/豆沙粉不幼稚）

## 六、常见配色速查表（上衣 → 下装/鞋包）

| 上衣颜色 | 推荐下装 | 推荐鞋 | 避坑 |
|---------|---------|--------|------|
| 白 | 藏青/黑/卡其/牛仔蓝 | 白鞋/棕鞋/黑鞋 | 全身纯白 + 荧光色 |
| 黑 | 牛仔蓝/灰/卡其/白裤 | 黑鞋/白鞋 | 全身黑（可加亮配饰破局） |
| 藏青 | 白/米白/灰/卡其 | 棕鞋/白鞋 | 藏青+黑（太暗） |
| 灰 | 黑/白/牛仔/酒红 | 白鞋/黑鞋 | 灰+土黄 |
| 卡其 | 白/藏青/驼色 | 棕鞋/白鞋 | 卡其+橘红 |

| 军绿 | 黑/卡其/牛仔 | 黑鞋/棕靴 | 军绿+荧光绿 |

## 七、配色比例法则

- 经典比例：主 70% / 辅 25% / 点缀 5%（点缀色 = 鞋/包/丝巾/帽子）
- 一个造型最多 3 个色系（图案色算一个）
- 想显高：上下同色系 + 鞋同色（视觉拉长）
- 想显瘦：深色集中在下半身或腰侧
